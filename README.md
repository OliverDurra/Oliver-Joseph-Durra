# Oliver Joseph Durra

Biography website for Oliver Joseph Durra — CEO of Aeolian Industries, inventor of H-Code, H-Wave and Durra Grid, author and historian.

Static site: `index.html`, `styles.css`, `script.js`. No build step.

## Run locally

```bash
python3 -m http.server 8000
```

## Publish with GitHub Pages

Settings → Pages → Deploy from branch → `main` / root.

## Confidentiality

This site describes H-Code, H-Wave and Durra Grid only at a public, non-technical level. Do not add architecture, algorithms, parameters or source from the private repositories.
